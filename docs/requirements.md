# 需求与背景（P083-llm-wiki-upstream）

## 项目目的

克隆上游 `nashsu/llm_wiki` 作为**源码真本**（v0.6.11），解决三个问题：

1. **诊断**：安装版 LLM Wiki.app 在知识库大规模目录迁移后重启时，批量剥离页面 `[[双链]]`、截断 frontmatter `related:` 的具体例程与触发条件；
2. **评估/开发**：为侧栏知识树增加「按文件夹分组」维度，使文档大分类（如文献/会议纪要/课题方案/设计准则/国内外标准）直接呈现在知识树；
3. **参考**：任何安装版行为与本地旧分叉（P026，0.6.0）不一致时，以本目录为准。

## 范围与假设

- 仅做源码阅读与静态诊断时无需安装依赖；构建/运行需 Node + Rust（Tauri）。
- 默认不向上游提 PR；如修复具有通用价值，经用户确认后再开分支整理。
- 假设：安装版 0.6.11 与 `release: v0.6.11` 提交（e808211）一致，或差异可通过 release 记录核对。

## 非目标

- 不替代 P026-dttn-msre-wiki（用户自有 0.6.0 分叉，保留不动）；
- 不改动 MSRE 知识库内容（`/Users/joe/msre wiki` 有独立维护规程）。
